# ملفات المحتوى المطلوبة من م. ردينة

> هذه الملفات جاهزة في المستودع بحالة `placeholder` (فارغة). عليك تعبئتها فقط **دون تغيير أسماء الملفات أو أسماء الحقول**، والكود سيقرؤها تلقائيًا.
> بعد كل تعديل شغّلي: `python3 scripts/validate_content.py`، ولا ترفعي ملفًا قبل ظهور «✅ لا أخطاء».

## قواعد عامة لكل الملفات
- الصيغة **JSON** بترميز UTF-8. أسهل طريقة: افتحي الملف الموجود وانسخي شكل المثال.
- كل ملف في أعلاه:
  - `status`: `placeholder` (فارغ)، أو `draft` (قيد العمل)، أو `verified` (مُراجَع وجاهز).
  - `reviewed_by`: اسم المراجِع وتاريخ المراجعة (`YYYY-MM-DD`). **إلزامي عند `verified`.**
- لا تكتبي أي شيء غير موجود في مصدر معتمد (الجمهرة، QuranEnc/مجمع الملك فهد، الدرر السنية). ضعي رابط المصدر دائمًا.
- كل ملف على حدة: ارفعي كل ملف عندما يجهز، ولا تنتظري الباقي.

## 1) ترجمات معاني القرآن المعتمدة
**المكان:** `data/quran/translations/en.json` و`data/quran/translations/fr.json`
**الأولوية:** 🔴 الأعلى. بدونها لا تظهر ترجمة أي آية.

```json
{
  "status": "verified",
  "language": "en",
  "edition": "Saheeh International",
  "translator": "Saheeh International",
  "publisher": "QuranEnc / مركز رواد الترجمة",
  "source_url": "https://quranenc.com/en/browse/english_saheeh",
  "license": "اكتبي نص شرط الاستخدام كما في الموقع",
  "retrieved": "2026-10-03",
  "reviewed_by": { "name": "ردينة بلال", "date": "2026-10-03" },
  "verses": {
    "1:1": "In the name of Allah, the Entirely Merciful, the Especially Merciful.",
    "2:153": "O you who have believed, seek help through patience and prayer. Indeed, Allah is with the patient."
  }
}
```

**الشروط:**
- المفتاح `"سورة:آية"` بالأرقام، مثل `"2:153"`. النص هو ترجمة الآية فقط، بدون رقمها ولا الحواشي.
- **الأفضل القرآن كاملًا (6236 آية)** إن كان الترخيص يسمح بالتنزيل. QuranEnc يوفّر ملفات جاهزة للتنزيل لكل ترجمة.
- إن لم يُتح ذلك، فالحد الأدنى:
  - كل آية مذكورة في المسرد؛
  - كل آية في مجموعة الاختبار (`expect.quran_refs`)؛
  - كل آية في أمثلة العرض.
- اكتبي اسم الإصدار كما سيظهر للمستخدم في `edition`.
- للفرنسية: نفس الشكل مع `"language": "fr"` (مثلًا ترجمة حميد الله من مجمع الملك فهد).
- تأكدي أن الإصدار الإنجليزي هو نفسه المكتوب في الموقع. الموقع يعرض حاليًا «Hilali & Khan»، فبلّغي م. فارس إن اخترتِ غيره.

## 2) قائمة الأحاديث
**المكان:** `data/hadith/hadith.json` (الأحاديث الثابتة) و`data/hadith/fabricated.json` (أقوال منتشرة لا تصح)
**الأولوية:** 🟠

`hadith.json`:
```json
{
  "status": "verified",
  "reviewed_by": { "name": "ردينة بلال", "date": "2026-10-03" },
  "items": [
    {
      "id": "h_niyyat",
      "text_ar": "إنما الأعمال بالنيات",
      "variants_ar": ["إنما الأعمال بالنية", "الأعمال بالنيات"],
      "collection": "bukhari",
      "number": "1",
      "grade": "صحيح",
      "source_url": "https://dorar.net/h/..."
    }
  ]
}
```

`fabricated.json`:
```json
{
  "status": "verified",
  "reviewed_by": { "name": "ردينة بلال", "date": "2026-10-03" },
  "items": [
    {
      "id": "f_seen_china",
      "text_ar": "اطلبوا العلم ولو في الصين",
      "variants_ar": ["اطلبوا العلم ولو بالصين"],
      "ruling": "موضوع",
      "source_url": "https://dorar.net/h/..."
    }
  ]
}
```

**الشروط:**
- `id`: إنجليزي قصير بلا مسافات، ولا يتكرر.
- `text_ar`: أشهر لفظ للحديث، بلا تشكيل ضروري. `variants_ar`: الصيغ الأخرى التي يكتبها الناس.
- `collection`: واحد من: `bukhari`، `muslim`، `abudawud`، `tirmidhi`، `nasai`، `ibnmajah`، `ahmad`، `malik`، `darimi`، `other`.
- `number`: رقم الحديث كما في الدرر. `grade`: الحكم كما في الدرر. `source_url`: رابط من `dorar.net` فقط.
- `ruling` في الموضوعات: موضوع، أو ضعيف جدًا، أو لا أصل له، أو ليس بحديث.
- **العدد المقترح:**
  - الأحاديث الثابتة: حوالي 50 من الأكثر تداولًا في المحتوى الدعوي، وكل أحاديث مجموعة الاختبار ضمنها.
  - الموضوعات: حوالي 20.

## 3) عبارات أسئلة الفتوى + رسالة الإحالة + الجهات
**المكان:** `data/policy/fatwa_signals.json` و`data/policy/referral.json`
**الأولوية:** 🔴

`fatwa_signals.json`:
```json
{
  "status": "verified",
  "reviewed_by": { "name": "ردينة بلال", "date": "2026-10-03" },
  "phrases": [
    { "text_ar": "هل يجوز لي", "kind": "personal_ruling", "note_ar": "طلب حكم شخصي" },
    { "text_ar": "في حالتي", "kind": "personal_context", "note_ar": "يدل على حالة بعينها" }
  ],
  "exclusions": [
    { "text_ar": "من أراد معرفة حكم", "note_ar": "جملة توعوية عامة، ليست سؤالًا شخصيًا" }
  ]
}
```

**الشروط:**
- `kind`:
  - `personal_ruling`: العبارة نفسها طلب حكم (هل يجوز، هل يحل، ما حكم، هل علي، هل يلزمني…).
  - `personal_context`: العبارة تدل على حالة خاصة (في حالتي، أنا مريض، أعيش في…).
- `exclusions`: عبارات تشبه الفتوى لكنها **ليست** سؤالًا شخصيًا، حتى لا يحيلها النظام بالخطأ (انظري الحالات T097 وT100 وT148).

`referral.json`:
```json
{
  "status": "verified",
  "reviewed_by": { "name": "ردينة بلال", "date": "2026-10-03" },
  "message": {
    "ar": "هذا سؤال يتعلق بحالتك الخاصة، والحكم فيه يحتاج إلى عالم مؤهل يسمع تفاصيلها. ننصحك بالتواصل مع جهة فتوى معتمدة.",
    "en": "…",
    "fr": "…"
  },
  "bodies": {
    "en": [ { "name": "…", "country": "UK", "url": "https://…" } ],
    "fr": [ { "name": "…", "country": "France", "url": "https://…" } ]
  }
}
```

**الشروط:**
- الرسالة رحيمة وقصيرة، لا تحكم ولا تخوّف، بالعربية والإنجليزية والفرنسية.
- الجهات: جهات فتوى معروفة وموثوقة للمسلمين في الدول الناطقة بالإنجليزية والفرنسية، مع رابط رسمي `https`.

## 4) نصوص التنبيهات التي تظهر للمستخدم
**المكان:** `data/messages/flags.ar.json`
**الأولوية:** 🟠

الملف موجود وفيه **مسودة لكل الرسائل** مأخوذة من الموقع الحالي. المطلوب مراجعتها وتحسين صياغتها شرعيًا ولغويًا، ثم تغيير `status` إلى `verified`.

**الشروط:**
- **لا تغيّري المفاتيح** (الكلمات الإنجليزية على اليسار) ولا تحذفي أيًا منها، فالكود يعتمد عليها.
- **احتفظي بالكلمات بين الأقواس `{...}` كما هي.** النظام يضع مكانها قيمًا تلقائيًا:
  - `{ref}`: رقم الآية
  - `{correct_text}`: نص الآية الصحيح
  - `{term}`: المصطلح
  - `{max_chars}`: الحد الأقصى لطول النص
  - `{retry_after}`: عدد الثواني قبل إعادة المحاولة
- أُضيفت خمسة مفاتيح يطلبها الخادم: `glossary_source` (مرجع المسرد) و`text_too_long` و`rate_limited` و`validation_error` و`general_error` (رسائل الأخطاء). صياغتها مسودة تحتاج مراجعتك.
  - `{word}`: الكلمة الخاطئة
  - `{ruling}`: حكم الحديث
  - `{refs}`: المواضع
- رسائل قصيرة: جملة أو جملتان.

## 5) أمثلة العرض
**المكان:** `data/demo/examples.json`
**الأولوية:** 🟡 (يحتاجها م. فارس للموقع والفيديو)

```json
{
  "status": "verified",
  "reviewed_by": { "name": "ردينة بلال", "date": "2026-10-03" },
  "items": [
    {
      "id": "d1_terms",
      "label_ar": "فقرة دعوية",
      "hint_ar": "مصطلحات + آية + حديث",
      "shows": "term_lock",
      "text_ar": "…",
      "expected": {
        "en": "الترجمة الإنجليزية الصحيحة المتوقعة",
        "fr": "الترجمة الفرنسية الصحيحة المتوقعة",
        "notes_ar": "ما الذي يجب أن يلاحظه المشاهد"
      }
    }
  ]
}
```

**المطلوب 5 أمثلة.** `shows` يحدد ما يعرضه كل مثال:
1. `term_lock`: مصطلح يخطئ فيه المترجم العادي.
2. `quran_mismatch`: آية منقولة بخطأ.
3. `hadith_unsourced`: قول منسوب للنبي ﷺ بلا مصدر.
4. `fatwa_referral`: سؤال فتوى شخصي.
5. `general`: فقرة دعوية عادية متكاملة.

⚠️ لا تأخذي أي مثال من مجموعة الاختبار (`data/testset/`)، حتى تبقى المقارنة عادلة.

## طريقة الرفع
1. عدّلي الملف على جهازك، ثم شغّلي: `python3 scripts/validate_content.py`
2. عند ظهور «✅ لا أخطاء» ارفعيه إلى GitHub.
   - من موقع GitHub: افتحي الملف ← أيقونة القلم ✏️ ← الصقي المحتوى ← Commit.
   - أو بالأوامر: `git add data/... && git commit -m "data(quran): add saheeh international en" && git push`
3. أبلغي م. محمد في القروب باسم الملف حتى يشغّل خطوة الدمج (Phase R).
